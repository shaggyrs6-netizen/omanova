# OMANOVA 0.1.3 — feature screenshots

Actual native-app captures taken on 14 November 2026 from the 0.1.3 source.
Click an image for the full-size PNG. The [original 0.1.2 gallery](SCREENSHOTS.md)
also covers ISS/Tiangong, Orbit, Moon, meteors, planets, comets, eclipses,
plumes, satellites, Starlink, aurora, the observing log and settings.

**Public sample data, not live observing advice.** These captures use a separate
fixture session with public Nashville/London locations. Launches and observing
examples are labelled demonstrations. Desktop light/dark palettes are samples;
the desktop theme was not changed. Terrain is calculated from cached public
elevation data for the sample point. Fixture dates and ended-window labels
remain visible. No personal location, log, favourites or other desktop content
is included. Some sample pages say “separate preview”; the same feature page
is included in the integrated Observatory, where examples are kept separate
from real saved data.
