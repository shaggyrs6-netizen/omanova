# OMANOVA 0.1.2 — screenshot gallery

Actual captures of the native Observatory, taken on 13 November 2026 from the
published 0.1.2 application code. Click any image to open the full-size PNG.

**These are demonstrations, not live observing advice.** The session uses
public Nashville/London sample locations, offline fixtures, fictional manual
obstructions and a separate sample log. Weather, launch/plume, train and aurora
examples are explicitly simulated. The terrain skyline uses cached public
elevation data for the Nashville sample point. Dates shown are fixture dates;
no personal location, observing log or desktop content is included.

The screenshots show the current dark design. Following the desktop theme is
a requested future option, not an implemented 0.1.2 feature.
